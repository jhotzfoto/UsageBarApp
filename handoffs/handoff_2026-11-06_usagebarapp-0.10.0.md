## How to work on it (gotchas learned)
- Session cwd was ../UsageBar (not a git repo), so EnterWorktree fails. Pattern used: `git worktree add .claude/worktrees/<name> -b <name>` inside UsageBarApp (`.claude/` is in .git/info/exclude), edit there, build/install from there, commit, then `git merge --ff-only` into main, `git worktree remove`, `git branch -d`. Josh approved merging to main ("merge").
- Writes to UsageBarApp, building, installing, iCloud files need `dangerouslyDisableSandbox` (sandbox only allows writes in ../UsageBar and $TMPDIR). $TMPDIR differs between sandboxed and unsandboxed runs.
- Edit tool refuses files not Read in the current worktree path: Read first.
- Big Swift Charts builders hit "unable to type-check in reasonable time": split into @ChartContentBuilder helpers; hover helpers return `some ChartContent` (no builder, since they use `var`).
- Design check without clicking: `~/Library/Developer/Xcode/DerivedData/UsageBarApp/Build/Products/Release/UsageBarApp.app/Contents/MacOS/UsageBarApp --render-history <path> [--line|--bars]` writes <path>-light.png / -dark.png with real data and quits (read-only: skips polling). No `timeout` binary; use `( cmd & P=$!; sleep 25; kill $P )`. Buttons/links render as yellow placeholders, that's normal.
- iPhone script tests: node with Proxy mocks of Scriptable APIs (Path, DrawContext, ListWidget, FileManager, args) caught issues; `node --check` on the script wrapped in an async IIFE for syntax.
- When updating Scriptable scripts in iCloud, Scriptable may have prepended a 3-line "Variables used by Scriptable" header; keep it, and don't overwrite if the body differs from the last committed version.
- Tests: `cd mac/UsageCore && swift test --scratch-path ~/Library/Developer/Xcode/DerivedData/UsageCore-spm`. Build+install: `zsh scripts/install-mac.sh` (unsandboxed). Then check `plutil -extract CFBundleShortVersionString raw ~/Applications/UsageBarApp.app/Contents/Info.plist` and `pgrep -x UsageBarApp`.
